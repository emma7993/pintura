# Exploración previa de Camino

Este directorio conserva la primera exploración y sus originales, incluidos borradores con más volumen y pintura. La selección actual pedida por el usuario para el nivel 1 está en `../Nivel_01_Camino/Bocetos_v001/`: grafito muy abierto, fondo casi blanco y capas parallax.

Los recursos de esta exploración no constituyen aprobación artística. Sus documentos LEVEL_PLAN y CAMINO_BIBLE contienen propuestas de diseño; no convierten esas mecánicas ni enemigos en funcionalidades implementadas.

Se conserva el proyecto de prueba como referencia histórica. El paquete de nivel 1 es el punto de entrada para trabajo posterior.
