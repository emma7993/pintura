# Flechas de pincel v002

Variante caricaturesca con contorno de carbón y grano de grafito. Los colores normales reutilizan la paleta de v001.

Seis flechas normales de punta redonda, con cuatro cuadros de estela por color. La flecha crítica roja tiene punta afilada, cuatro cuadros de estela y cinco de impacto.

Los PNG RGBA de 384×384 apuntan a la derecha. El ancla de referencia para flechas y estelas es (352,192) y para la salpicadura (192,192). Las estelas y la salpicadura se reproducen a 20 FPS una vez.

ASSETS.json lista las rutas. Atlases contiene una tira por secuencia. Godot/Pincel_Flechas.tres reúne las animaciones para la integración de Claude.
