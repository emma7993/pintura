# Nivel 1 — Camino

La selección específica del primer nivel está en `Bocetos_v001/`.

Dirección aprobada por el usuario: cuadro casi blanco que apenas empieza a dibujarse, grafito/lápiz, líneas suaves e incompletas. Las propuestas con piedra pintada, masas de óleo o vegetación terminada de `../Camino_World_v001/` quedan como exploración previa, no como selección final del nivel 1.

Mantener nuevas variantes aquí con versión propia. Las referencias originales y fuentes se preservan dentro del paquete. Los otros cuatro mundos continúan sin definir.
