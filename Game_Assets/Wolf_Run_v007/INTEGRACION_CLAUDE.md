# Carrera v007 — zancada corta y bufanda plana

Ocho sprites RGBA 384×384. Atlas horizontal run_atlas.png 3072×384. Godot/Wolf_Run.tres: run, 16 FPS, bucle. Offset (−192,−352).

La zancada es visualmente más compacta; no equivale a una distancia medida de avance del juego. Se recupera el acabado plano de la bufanda con grano de grafito, contorno gris y flecos cortos. Ojos abiertos pequeños. Manos compactas, brazos retrasados y pincel en la mano izquierda.

Se usa una escala y registro comunes para los ocho cuadros, sin normalizar la caja opaca individual de cada pose. Previews/run.gif muestra el ciclo; run_slow.gif facilita revisar cambios de forma y contact.png muestra todos los cuadros.

Sprites/ entrega el pincel integrado para revisión visual. No se incluyen capas de punta intercambiables en esta revisión. La consistencia dibujada y la transición entre cuadros requieren revisión del usuario; no se declara esta variante aprobada.

Source/ conserva el original, prompts y exportador. Imágenes creadas con la herramienta integrada de generación a partir de v006 y la referencia de bufanda enviada por el usuario. No se tocaron characters/, art/, código ni Git.
