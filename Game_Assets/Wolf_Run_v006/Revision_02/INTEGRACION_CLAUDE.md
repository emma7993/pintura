# Carrera v006 — revisión 02 seleccionada

Usar esta subcarpeta. La exportación en la carpeta superior es un borrador descartado por deformación en las orejas.

Ocho cuadros RGBA 384×384; atlas 3072×384. Offset (−192,−352), run 16 FPS en bucle. Ojo abierto más pequeño, cabeza reducida respecto a v005, manos más compactas y bufanda con pliegues de tela y flecos cortos.

El pincel está integrado en estos sprites para revisión visual; esta revisión no entrega capas independientes ni contactos para cambiar de punta. No sustituir automáticamente las animaciones del juego. Source conserva original y exportador. Generación mediante herramienta integrada de imágenes y prompt de corrección, a partir de las referencias del usuario y v004/v005.

No se tocaron characters/, art/, código ni Git. La continuidad y velocidad deben revisarse dentro del juego antes de integrar.
